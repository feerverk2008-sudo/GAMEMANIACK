# Последний сигнал

Браузерный пиксельный хоррор на Canvas 2D. Один маньяк против пяти выживших. Сервер использует только встроенные модули Node.js.

## Запуск

Установи Node.js, затем в папке проекта выполни:

```sh
npm install
node server.js
```

Открой `http://localhost:3000`. Несколько окон браузера подключаются к одному матчу. Для локального просмотра можно открыть `index.html`, но онлайн-игра требует сервер.

## Управление

- WASD или стрелки — ходьба.
- Shift — рывок выжившего.
- E — удерживать для ремонта генератора, расшифровки ворот, подъёма, спасения из клетки или починки.
- Пробел — удар маньяка.
- На телефоне — джойстик и экранные кнопки.

## Редактор коллизий арены

- В главном меню выбери «Настроить коллизии».
- В редакторе WASD/стрелки перемещают персонажа сквозь карту. Выбери инструмент «Стена», «Поддон» или «Шкаф»; клетка под персонажем выделена рамкой.
- Пробел ставит или убирает выбранный объект; R поворачивает поддон. На телефоне для установки есть экранная кнопка.
- «Сохранить коллизии и выйти» возвращает в меню. После этого стены блокируют движение и обзор.
- Разметка сохраняется на сервере и синхронизируется во всех матчах, друзьях и локальной игре с ботами. Без сервера она сохраняется в браузере.
- Предыдущая автоматически заданная разметка отключена. Новая карта начинается без стен, чтобы её можно было собрать вручную.

## Что есть в MVP

- Выбор стороны и режима: быстрая игра, открытый матч, тренировка с ботами, матч с друзьями или редактор коллизий. Текстура арены — присланная карта бункера.
- Ограниченная карта с ограждением, узкими коридорами, открытыми залами, двумя воротами и центральной клеткой.
- Восемь обязательных генераторов и три запасных; долгий ремонт с удержанием E. у маньяка две поломки на матч.
- Три попадания до оглушения; первое даёт выжившему ускорение, раненый оставляет следы.
- После пятиисекундного захвата жертва появляется в центральной клетке, а на месте исчезновения остаётся дым. Две первые посадки можно пережить, если союзник успеет освободить за 60 секунд; третья посадка или истечение таймера выводят игрока в наблюдение.
- Опрокидываемые поддоны задерживают маньяка; шкафы скрывают выживших и позволяют маньяку их обыскивать.
- Боты для тренировки: маньяк в роли выжившего и четыре выживших в роли маньяка.
- Небольшие персонажи, медленный темп перемещения и приближённая камера.
- Текстура арены взята из присланной карты бункера.
- Прозрачные пиксельные арты девушки и маньяка, анимация шага/дыхания, удара, ранения, оглушения и переноса.
- Мини-карта, полосы состояния, никнеймы, проверка уникальности имени, друзья по точному нику, синхронизация через WebSocket.

## Структура

- `index.html` — интерфейс игры и меню матча.
- `style.css` — адаптивный HUD, меню и сенсорное управление.
- `client.js` — Canvas-карта, рисование персонажей, управление, задачи и WebSocket-клиент.
- `server.js` — HTTP/WebSocket-сервер, комнаты игроков, состояние матча и сохранение общей разметки и объектов в `world.json`.
- `assets/bunker-map.png` — карта бункера; `assets/survivors/` и `assets/killer/` — очищенные от фона спрайты из присланных изображений.

Комментарий в коде оставлен на русском. Текущая версия — игровой прототип: полноценные матчи с противником требуют второго подключённого игрока-маньяка или выжившего.

## Публикация: GitHub Pages + Render Free

Игра уже опубликована: https://feerverk2008-sudo.github.io/GAMEMANIACK/

Статический сайт размещён на GitHub Pages. Онлайн-матчи обслуживает Node.js/WebSocket на Render Free: https://last-signal-ws.onrender.com/health. Адрес WSS уже записан в переменную репозитория GitHub Actions `GAME_SERVER_URL`; workflow Pages собирает клиент с этим адресом.

### Ограничения бесплатного тарифа

- После 15 минут без входящих запросов или сообщений WebSocket Render останавливает бесплатный сервис. Следующее подключение может ждать примерно 50 секунд или дольше.
- У бесплатного сервиса нет постоянного диска. Файл `world.json` хранится во временной файловой системе и может сброситься при простое, перезапуске или повторной публикации. Это касается сохранённых друзей, коллизий и объектов карты.
- Публичный репозиторий подключён как Public Git Repository, поэтому обновления сервера публикуются вручную через Render Dashboard → сервис `last-signal-ws` → Manual Deploy.
- GitHub Pages не запускает `server.js`; для локальной игры запусти Node.js командами ниже.

Для публикации изменений интерфейса отправь изменения в `main` или запусти workflow `Опубликовать игру на GitHub Pages` в разделе Actions. Переменная `GAME_SERVER_URL` должна содержать URL формата `wss://<домен-сервера>`.
